# Medstrat — пиксельная стратегия по Европе и Средиземноморью

Глобальная 2D-стратегия в пиксельном стиле на **Godot 4.7** (GDScript). Карта — вся Европа,
Северная Африка и Левант, провинции — страны из данных Natural Earth. Игрок начинает за Италию,
остальные ~54 страны ведут боты. Строим города и порты, нанимаем войска, захватываем соседей
по суше и по морю.

## Требования

- macOS с Homebrew: `brew install --cask godot` (ставит Godot 4.7.x и команду `godot`).
- Python 3 (стоковый) — только для пересборки карты, внешних библиотек не нужно.

## Команды

```bash
python3 tools/build_map.py                        # GeoJSON -> assets/map/* (+ preview.png)
godot --path .                                    # запустить игру (главное меню)
godot --headless --path . -s tests/run_tests.gd   # тесты симуляции и карты
godot --path . scenes/game.tscn -- --screenshot=/tmp/shot.png             # скриншот старта
godot --path . scenes/game.tscn -- --demo --screenshot=/tmp/demo.png      # город, порт, атака
godot --path . scenes/game.tscn -- --run-ticks=3000 --screenshot=/tmp/bots.png  # 30 игровых минут ботов
```

Флаги после `--`: `--screenshot=PATH`, `--run-ticks=N`, `--fast` (x10 скорость), `--demo`.

## Управление

- Карта: ПКМ/СКМ с зажатием, WASD/стрелки или края экрана — двигать; колесо — зум (целые шаги).
- ЛКМ — выбрать провинцию (панель справа). Нижние плашки включают режим: город, порт, наём, атака.
- Атака: плашка «Атаковать» → своя провинция → подсвеченная цель. Или «Атаковать отсюда» в панели.
- Esc / ПКМ — отмена режима; Esc без режима — меню выхода («В главное меню» / «Выйти на рабочий стол»).

## Правила (см. `scripts/sim/rules.gd`)

- Месяц = 10 секунд. Доход провинции = `10 + 3·√(клетки)` (макс. при 10000 клеток), город +25, порт +15.
- Город 500 (защита +30), порт 300 (открывает атаки по морю на соседей через воду), наём 100 → +50 войск.
- Бой мгновенный: в атаку идут 75 % гарнизона; защита = гарнизон + 20 (+30 город). Побеждает большая сила,
  остаток атакующих занимает провинцию.
- Боты решают раз в 10 секунд: город → порт → наём → атака слабейшего соседа при перевесе 1.5×.
  Первые 6 месяцев игрока не трогают, доход ботов ×0.8.

## Структура

```
tools/build_map.py        генератор карты (чистый Python): растеризация, провинции, террейн, соседи
assets/map/               province_ids.dat, terrain.dat, provinces.json, preview.png (генерируются)
shaders/map.gdshader      вся карта одним шейдером: террейн + цвет владельца + границы + подсветки
scripts/map/              map_data (данные), map_view (спрайт+шейдер), building_layer, pixel_sprites
scripts/camera/           пиксель-перфект камера
scripts/sim/              rules, sim (состояние, действия, бой, доход), bot_brain
scripts/ui/               hud, exit_dialog, main_menu, theme_factory
scripts/game.gd           склейка: режимы ввода, сигналы симуляции, флаги командной строки
tests/run_tests.gd        headless-тесты
```

Все изменения состояния идут через словари-действия `sim.apply({type, player, ...})` — этот же
формат станет сетевым протоколом на этапе 5 (Godot high-level multiplayer, хост-авторитарно).
