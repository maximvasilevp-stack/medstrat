# Medstrat — захвати Европу

Стратегия про захват территории на карте Европы, Северной Африки и Леванта в духе territorial-игр:
стартуешь маленьким пятном, армия растёт сама, кликом по чужой или ничьей земле отправляешь
долю армии в атаку, и граница ползёт клетка за клеткой. Вокруг 12 ботов и 30 нейтральных
городов-государств. Матч длится 15 минут, побеждает тот, у кого больше земли.

Движок **Godot 4.7** (GDScript), карта строится из данных Natural Earth скриптом на чистом Python.

## Требования

- macOS с Homebrew: `brew install --cask godot` (Godot 4.7.x и команда `godot`).
- Python 3 (стоковый) — только для пересборки карты, внешних библиотек не нужно.

## Команды

```bash
python3 tools/build_map.py                        # Natural Earth -> assets/map/* (+ preview.png)
godot --path .                                    # запустить игру (главное меню)
godot --headless --path . -s tests/run_tests.gd   # тесты симуляции и карты
godot --headless --path . -s tools/balance_probe.gd   # как идёт матч у ботов по минутам
godot --path . scenes/game.tscn -- --seed=42 --screenshot=/tmp/shot.png           # скриншот старта
godot --path . scenes/game.tscn -- --seed=42 --demo --screenshot=/tmp/demo.png    # город + атака
godot --path . scenes/game.tscn -- --seed=42 --run-ticks=4500 --screenshot=/tmp/bots.png  # 7,5 минут ботов
```

Флаги после `--`: `--seed=N`, `--screenshot=PATH`, `--run-ticks=N`, `--fast` (x10), `--demo`, `--open-exit`.

## Что есть в матче

- Выбор точки старта кликом (20 секунд, иначе игра поставит сама), 12 ботов и 30 городов-государств.
- Свежезахваченные клетки светятся, так что фронты видно издалека. Панель слева показывает ваши атаки
  с кнопкой отзыва, корабли в пути и входящие атаки. Подсказка под курсором: кто владеет землёй,
  сколько у него войск и во что обойдётся захват клетки.
- Корабли: с портом клик по берегу за морем отправляет десант, который плывёт несколько секунд.
- Ядерная бомба (20K) и MEGA NUKE (80K): через 3 секунды земля в радиусе 10 или 18 клеток становится
  ничьей и выжженной на 90 секунд (захват вдвое дороже), владелец теряет войска пропорционально.
- Боты строят, расширяются, высаживаются с моря, отвечают на атаки и изредка бомбят крупных соседей.
- Миникарта с окном камеры (клик или перетаскивание — перемещение), горячие клавиши 1–5 для карточек,
  M — звук, процедурные звуки без аудиофайлов, ник сохраняется между запусками.

## Экономика и развитие

- Старт: 1500 золота, размещение столицы стоит 500. Золото капает с земли, портов и рынков.
- Постройки (клавиши 1–8, каждая следующая того же типа дороже на 50 %): Защита, Город, Порт, Рынок
  (+12 золота/с), Казармы (+800 к лимиту и +0.3 % роста), Бункер (сбивает чужие бомбы в радиусе 16),
  Ядерная бомба и MEGA NUKE.
- Меню «Развитие» (T): Торговля, Призыв, Логистика, Фортификация, Тактика, Навигация, Ядерная программа
  и Ракеты — по 1–3 уровня за золото; бомбы доступны только после ядерных технологий. Боты тоже
  изучают технологии и строят рынки, казармы и бункеры.
- Секретный код `666` (поле в меню Esc) даёт бесконечные золото, армию и все технологии.
- Карта: настоящие города Европы, Северной Африки и Ближнего Востока как нейтральные города-государства,
  леса, холмы у гор, степь, границы стран.

## Народ и политика

- Одобрение (0–100) тянется к цели: налоги и идущие войны его снижают, рынки и города поднимают.
  Оно умножает рост армии (×0.6 … ×1.4). Ниже 25 % народ уходит с окраин, и вы теряете клетки.
- Налоги 0–3 уровня дают золото с населения. Указы: Пропаганда (+12), Праздник (+20 и +10 % роста на
  минуту), Мобилизация (+15 % лимита войск сразу, −15 одобрение). Всё в панели «Народ» (P).
- Выборы каждые 3 минуты: при одобрении ниже 50 % — поражение и минута штрафа к росту и золоту.
- Случайные события с выбором из двух вариантов раз в 1–2 минуты: засуха, мятеж, беженцы, эпидемия…
- Боты тоже управляют налогами и пропагандой.
- Меню (Esc или кнопка слева сверху): продолжить, звук, секретный код, выход.

## Правительство (G)

- **Госдума**: 100 мест делят четыре партии — Партия порядка, Торговый союз, Народный фронт,
  Технократы. Места пересчитываются на каждых выборах по тому, как вы правите (казармы и войны,
  рынки и налоги, довольный народ, технологии). Правящая партия даёт бонус. Агитация за 2K золота
  добавляет партии голосов до следующих выборов.
- **Министры**: финансов (+15 % золота), генерал (фронт быстрее), дипломат (боты нападают реже),
  учёный (технологии дешевле), пропагандист (+8 к одобрению). Найм платится один раз, зарплата
  списывается каждую секунду.
- **Законы**: военная реформа, свободная торговля, социальный пакет, наука в приоритете,
  чрезвычайное положение. Закон проходит, если поддерживающие партии держат не меньше 50 мест.
- **Графики**: золото, армия, земля и одобрение за матч, разбивка дохода по источникам.
- Цвет своей территории выбирается в главном меню из шести цветов палитры.

## Управление

- **ЛКМ по чужой или ничьей земле** — атака: уходит доля армии по ползунку «ATTACK SIZE», фронт
  двигается от вашей границы. По ничьей земле можно кликать куда угодно, расширение идёт от границы.
- Высадка с моря: постройте порт, затем кликните по береговой клетке за морем.
- Карточки внизу — режим постройки, потом клик по своей земле: **Защита** (захват ваших клеток
  дороже), **Город** (выше лимит и рост армии), **Порт** (золото и высадки). Каждая следующая
  постройка того же типа дороже на 50 %.
- ПКМ/СКМ с зажатием, два пальца на трекпаде, WASD/стрелки, края экрана — двигать карту; колесо,
  щипок, клавиши + и − или кнопки у карты — зум; Esc — отмена / меню; M — звук.

## Правила (все числа в `scripts/sim/rules.gd`)

- Армия растёт на 1.2 % себя в секунду плюс 0.06 за клетку плюс 10, до лимита `300 + 6·клетки + 1500·города`.
- Золото: `1 + 0.05·клетки + 10·порты` в секунду. Город 2.5K, защита 3K, порт 4K.
- Захват ничьей клетки стоит 3 войска × (1 + ваши клетки / 1000); клетки врага — ещё × (1 + плотность
  его войск) × (1 + 0.5·его защита). Песок ×1.3, снег ×2, горы ×3. Защитник теряет половину потраченного.
- Фронт продвигается на `√(войск в атаке)/6` клеток за тик (1…6), тик = 0.1 с.
- Боты думают раз в 3 секунды: постройки, расширение в пустоту при 35 % лимита, атака самого
  дешёвого соседа при 60 %. Первую минуту игрока не трогают.

## Структура

```
tools/build_map.py        генератор карты: суша, проливы, пустыни, горы, реки, озёра, берег
tools/balance_probe.gd    прогон матча ботов по минутам
tools/data/               Natural Earth (public domain): страны, реки, озёра, регионы
assets/map/               terrain.dat, coast.dat, map.json, preview.png (генерируются)
shaders/map.gdshader      террейн + цвета владельцев + границы; wood.gdshader — рамка
scripts/sim/world.gd      симуляция: владельцы клеток, рост, атаки, постройки, рейтинг
scripts/sim/bot_brain.gd  боты;  rules.gd — баланс;  names.gd — имена
scripts/map/              map_data, map_view, world_scene (ввод), building_layer, pixel_sprites
scripts/camera/           камера с целым зумом внутри SubViewport
scripts/ui/               hud (карточки, армия, золото, лидерборд), map_labels, exit_dialog, main_menu
scripts/game.gd           сцена матча: рамка, SubViewport, сигналы, флаги командной строки
tests/run_tests.gd        headless-тесты (карта, спавн, рост, атаки, постройки, детерминизм, прогон)
```

Все действия игрока — словари `world.apply({type, player, ...})`, симуляция детерминирована по seed.
Это заготовка под сетевую игру: хост применяет действия и рассылает состояние.

## Версия для браузера и публикация на GitHub Pages

Сборка (нужны экспортные шаблоны Godot 4.7.2, они уже установлены на этом Mac):

```bash
godot --headless --path . --export-release Web docs/play.html
```

`docs/index.html` — сайт игры (описание, скриншоты, вход по нику и паролю; профили хранятся в браузере
игрока, сервера нет), `docs/play.html` — сама игра, ник передаётся из сайта в игру.

Проверка у себя: `python3 -m http.server 8080 --directory docs` и открыть http://localhost:8080.

Публикация (один раз):
1. Создайте пустой репозиторий на github.com, например `medstrat`.
2. В терминале: `git remote add origin git@github.com:ВАШ_НИК/medstrat.git` и `git push -u origin main`.
3. На GitHub: Settings → Pages → Source: «Deploy from a branch», Branch: `main`, Folder: `/docs` → Save.
4. Через минуту игра будет по адресу `https://ВАШ_НИК.github.io/medstrat/`.

Каждое обновление: пересобрать командой выше, затем `git add docs && git commit -m "web build" && git push`.
